
Overview

A comparator is a combinational digital circuit used to compare two binary numbers and determine their relative magnitudes.

Objectives

- To design a digital comparator using Verilog HDL.
- To compare two binary inputs.
- To determine whether the first input is greater than, less than, or equal to the second input.

Operations

- A > B: Greater than
- A < B: Less than
- A = B: Equal to

Implementation

The comparator is described using Verilog HDL and verified through simulation using a testbench.

Expected Result

The circuit produces the correct comparison output for different combinations of binary inputs.
